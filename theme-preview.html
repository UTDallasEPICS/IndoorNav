Indoor Nav color themes

Twelve two-color themes for the SPN map screen. Each phone uses the same layout as app/pages/map.vue; only the two colors change. Text on the solid color switches between white and near-black, whichever is easier to read.

Solid: Find Route button, active floor, your arrow, set-location pin Accent: route line, destination pin and room, links, input underline
Real SPN Level 1 floor plan with an A* route from the main lobby to 1.110 Fabrication Lab.
